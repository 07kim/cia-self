# 画面遷移

## 通常利用

- `home → points`
- `points → pointScan`: CIA POINTまたは提携ポイントを選択。読取成功遷移はなく、この画面で停止する。
- `points → bag`: `利用しない`を選択。
- `bag → payment`: レジ袋小・大は買い物かごへ1点追加し、不要は袋商品を追加しない。
- `payment → checkout`: 支払方法を保持してカメラを開始する。
- `checkout → payment`: 読取中、権限待ち、起動失敗時の「戻る」で支払方法選択に復帰する。カメラを停止し、遅延した起動完了を無効化する。会計内容は破棄しない。
- `checkout → settlement`: 商品またはレジ袋が買い物かごに存在するときだけ進める。
- `settlement`: 決済端末待機で停止し、完了遷移は持たない。

## 手動復帰とリセット

- `はじめに戻る`、`取引を中止`、従業員モードの`セルフレジへ戻る`で`home`へ戻る。
- `home`へ戻るとポイント、レジ袋、支払方法、買い物かご、検索、選択中履歴、カメラ状態を破棄する。
- 無操作時間では画面遷移も状態リセットも行わない。

## 係員呼出

- すべての係員ボタンは`staffConfirm`を開く。
- `呼ばない`または背景操作で元画面へ戻る。
- `係員を呼ぶ`で`staffCalled`へ切り替え、呼出完了と混雑時の注意を表示する。

## 管理機能

- 通常利用画面の左上→右上→左下→右下で`lock`を開く。
- `lock → home`は認証画面の`戻る`で遷移し、入力内容と認証エラーを破棄する。
- 正しいパスワードで`employee`、不正解で`home`へ戻る。
- `employee → history`で購入履歴を開く。見出しと検索欄は固定し、一覧と明細だけをスクロールする。
- `employee → employeeId`で数字テンキーの従業員ID認証を開く。
- `employeeId`で`20261107`を照会した場合だけ`puzzleSettings`へ進む。それ以外のIDは入力を消去し、該当なしを表示する。
- `puzzleSettings`で保存した画像と正解は次回以降の`lock`へ反映する。従業員メニューへ戻っても保持し、初期設定操作のみでリセットする。
