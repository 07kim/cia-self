# cia-self 製品仕様

- iPad向けの売店セルフレジ体験と、隠し操作から開く購入履歴管理画面を提供する。
- iPadを横向き・全画面で使用する。実店舗のセルフレジらしい白基調の明るい画面、明確な手順表示、大きな読取領域、レシート状の商品一覧、常に見える合計と次操作を持つ。監視カメラシステムのような高密度な装飾や、管理端末に見える暗い配色は使用しない。
- 初期画面からカメラ式の商品読取、買い物かご、内容確認まで操作できる。画面内に「デモ」という表現は表示しない。
- 初期画面は挨拶だけを大きく見せず、買い物開始、商品コード入力、使い方、係員呼出、表示言語、文字サイズ、効果音を選べるセルフレジメニューとする。表示したボタンはすべて状態変化または案内を返す。
- 初期画面と商品読取画面に独立した共通ヘッダーは置かない。ブランドは初期案内カード内、効果音は初期メニューと商品読取パネル内へ配置する。
- 商品読取は端末のカメラを使用し、実在商品のJAN-13/JAN-8と、CIA MART内でのみ使用する20〜29から始まるインストアコードを扱う。
- 読み取ったコードは端末内の商品台帳と照合する。商品台帳にはバーコード、商品名、価格、税率、分類、画像、販売状態を登録する。
- 登録済み商品は買い物かごへ追加し、点数、数量、小計、合計を更新する。同一コードの連続誤検知は抑止する。
- 未登録コードは商品として追加せず、コード番号と「商品が登録されていません。係員をお呼びください」を表示する。
- 実在商品とCIA MARTオリジナル商品を同じ操作で読み取れるようにする。
- 読取成功、未登録、操作、完了を区別できる短い効果音を使用する。音声ファイルと商品情報は端末内に保持し、通信なしでも動作する。
- 初回の明示的な画面操作で音声利用を開始し、ブラウザの自動再生制限に対応する。常時鳴る環境音やBGMは使用しない。
- 左上、右上、左下、右下をZ字順にタッチすると管理認証を開く。クリック完了を待たず`pointerdown`または`touchstart`で判定し、同じタッチから両イベントが発生しても1回として扱う。各タッチでは端末比率に左右されない固定サイズの青い円形反応を表示し、iOS標準の灰色タップ表示は出さない。
- Z字タッチは各正解タッチから次の正解タッチまでを1.5秒以内とする。正しい角を押すたびに1.5秒を計り直し、いずれかの間隔が1.5秒を超えた場合または順番を間違えた場合は進行をリセットする。左上を押した場合は新しい入力の1点目として扱う。
- 暫定パスワードは「ばいてん」。正解時は購入履歴、商品台帳、端末状態、取引設定を選べる従業員モードを開き、不正解時は初期画面へ戻る。謎画像は差し替え可能にする。
- 購入履歴は氏名・社員IDで検索でき、取引番号、時刻、氏名、社員ID、合計、端末、支払方法、商品名、バーコード、数量、単価を表示する。
- 証拠記録は`20:15 / 一ノ瀬 なつき / 0719 / ¥580`。四ツ谷または社員ID1031は表示しない。
- 管理認証と購入履歴は10秒間、通常の商品読取画面は60秒間操作がない場合に初期画面へ戻る。カメラ許可や商品を持ち替える時間を放置と誤認しないようにする。
- 固定データを使用し、通信とデータベースなしでも動作する。

## 通常セルフレジの画面構造

- 初期画面の主操作は大きな`START`面とし、商品コード、使い方、係員を短い補助操作として隣接配置する。`セルフレジ`、挨拶、操作説明を大見出しとして重ねず、ブランド、主操作、補助操作の大小差だけで役割を理解できる構成にする。
- 初期画面は画面全体を広く使い、大きな白い説明カードで左右を囲わない。角丸四角は押せる選択肢へ限定し、見出し、進行表示、説明領域を習慣的に枠で囲わない。
- 商品コード入力、使い方、係員呼出、表示言語は背景上のダイアログで開き、背景タッチまたは閉じる操作で戻れる。
- 左側に現在の案内とカメラ読取領域、右側に買い物かごを表示し、読み取り中も全体構造を変えない。
- 通常フローは`初期画面 → ポイント → レジ袋 → 支払方法 → 商品登録 → 会計完了`とする。前半の選択内容を商品登録画面まで保持して表示する。
- 商品登録はカメラ読取に加え、画面内の商品タイルからも行える。カメラを利用できない端末でも固定商品を選択し、一連の会計体験を完了できるようにする。
- ポイント、レジ袋、支払方法、商品登録、完了は常に同じ進行表示を持ち、現在位置と完了済みの段階を示す。
- ポイント、レジ袋、支払方法の選択画面は、選択肢をまとめる大きな外枠を持たず、見出しと操作タイルを余白で分ける。進行表示は角丸コンテナではなく細い区切り線と現在位置の下線で示す。
- 選択画面は上段に大きな質問見出し、下段に画面幅を使った大きな選択肢を置く。ポイント画面では「貯める／使う」を直接選ばせず、`CIA POINT`、提携ポイント、利用しないからカード種別を選ぶ。
- iPad横向きを主対象としつつ、iPad縦向きと狭幅ブラウザでは選択タイル、商品登録、従業員モードを1列へ積み替え、横スクロールを発生させない。
- カメラ許可が拒否された場合は、設定方法と初期画面へ戻る操作を表示する。
- 使用カメラは実機で前面・背面を比較し、読み取り精度と設置姿勢を確認して決定する。

## 効果音

- 操作音: 主要ボタンの確定を伝える短い音。
- 読取成功音: 商品が追加されたことを伝える単発音。
- 未登録音: 成功音と明確に異なる短い二音。
- 完了音: 取引完了時のみ使用する短い音。
- 四隅の隠し操作は通常利用者に気づかせないため、専用音を鳴らさない。
