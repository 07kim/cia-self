# cia-self 製品仕様

- iPad向けの売店セルフレジ体験と、隠し操作から開く購入履歴管理画面を提供する。
- iPadを横向き・全画面で使用する。実店舗のセルフレジらしい白基調の明るい画面、明確な手順表示、大きな読取領域、レシート状の商品一覧、常に見える合計と次操作を持つ。監視カメラシステムのような高密度な装飾や、管理端末に見える暗い配色は使用しない。
- iPadの操作・アクセシビリティはApple Human Interface Guidelinesを必須基準とする。主要タッチ領域は44×44pt以上とし、Safe Area、表示領域、文字サイズ、日英の文字長へ適応する。Apple標準アプリの外観を模倣せず、CIA MARTのセルフレジデザインを維持する。
- 初期画面からポイントカード・レジ袋・支払方法を選択し、商品登録の読取待機まで操作できる。画面内に「デモ」という表現は表示しない。
- 初期画面は挨拶だけを大きく見せず、お会計、使い方、係員呼出を選べるセルフレジメニューとする。商品コードの手入力は表示しない。
- 通常利用画面に固定ヘッダーは設けない。CIA MART表記は初期画面の主操作へ含め、表示言語、文字サイズ、効果音は初期画面右上の独立操作として表示する。
- 日本語と英語を切り替えられる。日本語の主操作は`START`ではなく「お会計」と表示し、英語では`CHECKOUT`とする。
- 商品登録はポイントカードと同じ読取待機画面として表示し、カメラ権限要求・映像表示・バーコード読取・自動成功を行わない。
- 読取成功、未登録、主要操作を区別できる短い効果音を使用する。音声ファイルと商品情報は端末内に保持し、通信なしでも動作する。
- 初回の明示的な画面操作で音声利用を開始し、ブラウザの自動再生制限に対応する。常時鳴る環境音やBGMは使用しない。
- 左上、右上、左下、右下をZ字順にタッチすると管理認証を開く。クリック完了を待たず`pointerdown`または`touchstart`で判定し、同じタッチから両イベントが発生しても1回として扱う。四隅には120×120pxの判定領域を確保し、各タッチでは小さな淡い光点から薄い二重波紋が約1.1秒かけて広がり消える。輪郭の強い固定円は表示しない。右上の通常メニューは判定領域と重ならない位置へ離し、iOS標準の灰色タップ表示は出さない。
- Z字タッチは各正解タッチから次の正解タッチまでを2.5秒以内とする。正しい角を押すたびに2.5秒を計り直し、いずれかの間隔が2.5秒を超えた場合または順番を間違えた場合は進行をリセットする。左上を押した場合は新しい入力の1点目として扱う。
- 初期パスワードは「セルフレジ」。認証入力欄にはプレースホルダーを表示せず、入力欄の外に「カタカナで入力してください」と形式だけを案内する。認証画面を開いた直後は入力欄へ自動フォーカスしない。利用者が入力欄を選んだ時だけソフトウェアキーボードを開く。認証画面の「戻る」で入力内容を破棄して初期画面へ戻れる。正解時は購入履歴、商品台帳、端末状態、取引設定、従業員ID認証を選べる従業員モードを開き、不正解時は初期画面へ戻る。
- 認証入力は画面内QWERTYキーボードを使用し、iPad標準キーボードや予測変換を表示しない。「英字／日本語」を切り替え、日本語ではローマ字をカタカナへ変換する。日本語配列のキーボードは使用しない。
- 従業員ID認証は数字テンキーを使う。`20261107`だけが謎設定を開き、それ以外は「該当する従業員IDがありません」と表示して同じ画面に残る。
- 謎設定では正解パスワードと謎画像を端末内に保存できる。保存した画像は認証画面に表示する。初期設定に戻すと「セルフレジ」と画像なしへ戻る。
- 購入履歴は氏名・社員IDで検索でき、取引番号、時刻、氏名、社員ID、合計、端末、支払方法、商品名、バーコード、数量、単価を表示する。
- 購入履歴はPC・iPad横では一覧と明細を大きく並べ、iPad縦と狭幅では一覧の各取引をラベル付きカードへ切り替え、明細を下段へ積み替える。表を画面幅に合わせて過度に縮小しない。
- 証拠記録は`19:15 / 一ノ瀬 拓実 / 0719 / ¥580`。四ツ谷または社員ID1031は表示しない。
- 会計フロー中に10秒操作がない場合は、画面を覆わない青系のポップアップと短い通知音で「まもなくホーム画面へ戻ります」と案内する。さらに10秒操作がなければ初期画面へ戻り、会計状態を破棄する。案内中に操作した場合は案内を閉じ、10秒の待機を再開する。
- 固定データを使用し、通信とデータベースなしでも動作する。
- 通常利用画面と従業員画面は端末の表示領域へ固定し、ページ全体をスクロールさせない。商品一覧、購入履歴、商品台帳など内容量が変動する領域だけを画面内スクロールとする。

## 通常セルフレジの画面構造

- 初期画面の主操作は大きな「お会計」面とし、使い方と係員を短い補助操作として隣接配置する。`セルフレジ`、挨拶、操作説明を大見出しとして重ねず、主操作と補助操作の大小差だけで役割を理解できる構成にする。
- 初期画面は画面全体を広く使い、大きな白い説明カードで左右を囲わない。角丸四角は押せる選択肢へ限定し、見出し、進行表示、説明領域を習慣的に枠で囲わない。
- 使い方と係員呼出は背景上のダイアログで開き、背景タッチまたは閉じる操作で戻れる。係員は「係員を呼びますか？」の確認後に呼び出し、完了後は混雑時に時間がかかる場合や対応できない場合がある旨を丁寧に案内する。
- 左側に現在の案内と読取待機領域を表示し、待機中も全体構造を変えない。
- 通常フローは`初期画面 → ポイント → レジ袋 → 支払方法 → 商品登録 → 支払い待機`とする。ポイントカードを選択した場合はポイント読取待機で停止し、`利用しない`を選択した場合だけレジ袋へ進む。
- 商品登録は読取待機で停止し、画面内の商品選択、手入力、カメラ操作は提供しない。
- レジ袋の小または大を選択した場合は、対応する価格の商品として買い物かごへ1点追加する。不要を選択した場合は追加しない。
- ポイント、レジ袋、支払方法、商品登録、支払いは常に同じ進行表示を持ち、現在位置と完了済みの段階を示す。
- 商品登録後は選択した支払方法、点数、レジ袋、合計、決済端末の待機状態を表示する。参加者が実際に決済できないため、支払い完了ボタンや会計完了画面への導線は設けず、取引中止と係員呼出だけを提供する。
- ポイント、レジ袋、支払方法の選択画面は、選択肢をまとめる大きな外枠を持たず、見出しと操作タイルを余白で分ける。進行表示は角丸コンテナではなく細い区切り線と現在位置の下線で示す。
- 選択画面は上段に大きな質問見出し、下段に画面幅を使った大きな選択肢を置く。ポイント画面では「貯める／使う」を直接選ばせず、`CIA POINT`、提携ポイント、利用しないからカード種別を選ぶ。
- iPad横向きを主対象としつつ、iPad縦向きと狭幅ブラウザでは選択タイル、商品登録、従業員モードを1列へ積み替え、横スクロールを発生させない。
- iPad横向きでは各画面をスクロールなしで完結させる。縦向き・狭幅で全操作を同時表示できない場合もページ本体は固定し、選択肢など必要な作業領域だけを内部スクロールさせる。
- 購入履歴は見出しと検索欄を画面内に固定し、取引一覧と商品明細だけをそれぞれスクロール可能にする。
- フォントの太字は金額、現在の操作、主要ボタンへ限定し、補助情報は標準ウェイトとする。均等な角丸カードの反復を避け、実機の固定領域と作業領域が分かる構成にする。
- カード、ポイント読取、レジ袋、支払方法、言語、音量などの機能表示には、同じ線幅・角・比率を持つ統一SVGアイコンを使用する。文字記号やCSSで描いた即席図形を機能アイコンとして使用せず、装飾が見出しや説明へ重ならない余白を確保する。

## 効果音

- 操作音: 主要ボタンの確定を伝える短い音。
- 読取成功音: 商品が追加されたことを伝える単発音。
- 未登録音: 成功音と明確に異なる短い二音。
- 四隅の隠し操作は通常利用者に気づかせないため、専用音を鳴らさない。
