# 設計判断

## 採用

- iPad向けの操作・アクセシビリティはApple HIGを必須基準とする。44×44pt以上の主要タッチ領域、Safe Area、可変表示領域と文字サイズ、明確な反応、目的のあるモーション、必要な時点でのカメラ権限要求を適用する。ただしApple標準アプリの外観は模倣せず、CIA MARTの白・青を基調とした実店舗セルフレジ表現を維持する。従業員用Z字タッチは参加者の必須導線ではない意図的なイベント例外とする。
- 商品登録はカメラ読取だけに限定し、参加者向けの商品タイルと商品コード手入力を置かない。
- ポイントカード選択時は実在しない成功を演出せず、読取待機で停止する。
- レジ袋は買い物かごと合計に含まれる商品として扱う。
- 決済とポイント読取は外部端末がないため成功させず、待機状態を体験の終端とする。
- 係員呼出は確認を挟み、実店舗らしい丁寧な完了案内を表示する。
- 通常利用画面の固定ヘッダーは撤去し、日英切替、文字サイズ、音量は初期画面の独立操作として残す。
- 放置による自動復帰を廃止し、状態破棄は明示操作だけで行う。
- 太い文字と角丸カードを全要素へ反復せず、主要操作に限定する。
- 機能アイコンはローカルへ同梱した一貫性のあるSVGセットを使用し、文字記号やCSS図形による代用品を廃止する。
- キオスク端末ではページ全体を固定し、データ量が変わる作業領域にだけ内部スクロールを許可する。
- 謎画像と正解は、数字テンキーで`20261107`を照会した端末内設定から変更できる。設定はサーバーへ送らず、そのブラウザにだけ保持する。
- アップロード済みの謎画像は、認証画面で補助的なサムネイルではなく主情報として表示する。iPad横では大きな画像領域と右側の認証操作へ分け、縦横比を維持して画像全体を見せる。

## 不採用

- 画面から固定商品を選択する予備操作。
- 商品コードの手入力。
- ポイント読取や決済の時間経過による擬似成功。
- 画面単位の無操作タイマー。
- 外部CDNから読み込むアイコンフォントと、画面ごとに作り方が異なる即席アイコン。
- 画面上端を常時占有する共通ヘッダー。
- 端末内の謎設定だけのための外部DB、設定API、画像ストレージ。
